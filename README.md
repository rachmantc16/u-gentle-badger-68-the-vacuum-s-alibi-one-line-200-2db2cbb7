A robot vacuum, questioned about the one spot it missed, pleads a timestamped alibi: it was docked, charging, exactly on schedule — and the dust in question sits in territory long ago ceded to the broom. This program writes that single line of deadpan testimony (200 characters or fewer) to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```
